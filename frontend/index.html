O projeto

O que é e qual problema busca resolver

O projeto busca desenvolver um sistema inteligente de tradução de Libras em tempo real, com visão computacional e inteligência artificial, para facilitar a comunicação entre pessoas surdas e profissionais durante atendimentos presenciais.

Pessoas surdas ainda enfrentam dificuldades de comunicação em serviços públicos e outros ambientes de atendimento. A tecnologia entra como intermediadora, ajudando a reduzir essa barreira.

Como funciona

Do sinal à comunicação

  1. 1

    Captura

    A câmera captura os movimentos das mãos.

  2. 2

    Detecção

    O MediaPipe identifica os pontos das mãos.

  3. 3

    Reconhecimento

    O modelo de inteligência artificial classifica o sinal realizado.

  4. 4

    Tradução

    O sistema converte o sinal reconhecido em texto e/ou áudio.

  5. 5

    Comunicação

    A informação é apresentada ao atendente.

Tecnologias

O que está por trás do sistema

  • Py

    Python

    Linguagem utilizada no desenvolvimento e na integração principal do sistema.

  • CV

    OpenCV

    Captura e processamento de imagens.

  • MP

    MediaPipe

    Detecção e extração dos pontos das mãos.

  • TF

    TensorFlow

    Classificação dos sinais por meio de aprendizado de máquina.

  • Fl

    Flask

    Comunicação e integração entre os componentes do sistema.

  • PG

    PostgreSQL

    Armazenamento das estatísticas de utilização.

  • TTS

    gTTS

    Conversão de texto em áudio.

Objetivo geral

Para onde o projeto aponta

Desenvolver um sistema inteligente de atendimento em Libras para facilitar a comunicação entre pessoas surdas e profissionais durante o atendimento.

Ver os objetivos específicos

Tecnologia para aproximar pessoas.

A proposta é usar recursos computacionais para auxiliar na comunicação e contribuir para a inclusão de pessoas surdas.
